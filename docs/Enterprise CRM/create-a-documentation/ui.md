# User Interface

The User Interface page guides you through every component of the form builder, helping you structure your questions and design a professional survey or assessment easily. You will learn how to add various question types and organize your overall form flow.

## Building Your Form

Use the main canvas area to construct your form step by step. Begin by adding a title and description for context.

### Adding Questions

To introduce a new topic or question, click the element addition field on the main builder canvas. After selecting a type, you can configure its details, including the prompt text and any necessary options.

## Available Question Types

The form editor provides a wide variety of input types to gather specific kinds of data from respondents. You select these types from the sidebar menu when adding a new question.

### Text Input Fields

These fields capture written responses from you:

* **Short answer:** Use this type when you expect brief, single-line text inputs (e.g., names or quick numerical answers).

* **Paragraph:** Select this option if you require longer, detailed written explanations from the respondent.

### Selection and Choice Fields

These types restrict responses to predetermined options:

* **Multiple choice:** Respondents must select exactly one answer from a list of provided choices.

* **Checkboxes:** You allow respondents to select zero, one, or multiple answers from a list of available choices.

* **Dropdown:** Presenting the choices in a collapsed menu format saves space and is ideal for long lists of options.

* **Multiple choice grid / Checkbox grid:** Use grids when you need respondents to rate several items against specific criteria (e.g., rating multiple features using a single scale).

### Specialized Data Types

You can incorporate unique data collection methods into your form:

* **File upload:** This allows you to request that the respondent provide a document, image, or other file from their local device.

* **Linear scale:** You compel respondents to rate an item along a defined continuous gradient (e.g., rating satisfaction on a 1 to 5 scale).

* **Date:** Use this type when you need the respondent to input a specific calendar date.

* **Time:** Select this if you require the respondent to submit a precise time measurement.

## Managing Form Structure and Flow

The builder allows you to organize your form content beyond just questions:

* **Form Description:** Always include a clear description at the beginning of your form so respondents understand its purpose before they begin answering.

* **Sections (Not explicitly shown, but implied organization):** Although not visible in the provided snapshot, remember that professional forms often require grouping related questions into distinct sections to prevent overwhelm for the user.

By mastering these elements and question types, you can build robust, scalable forms tailored precisely to your data collection needs.
